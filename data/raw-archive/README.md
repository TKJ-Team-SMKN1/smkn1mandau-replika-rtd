# Arsip HTML hasil scrape

Folder `hasil_scrape_smkn1mandau/` berisi salinan HTML dan manifest CSV dari halaman publik yang digunakan sebagai bahan referensi proyek replika.

- File asli dan nama file dipertahankan.
- `daftar_halaman.csv` mencatat nama file dan URL sumber.
- Arsip berada di luar `public/` agar HTML tidak disajikan atau dieksekusi sebagai halaman aktif pada origin situs replika.
- Jangan menganggap isi arsip sebagai informasi operasional terkini. Periksa sumber asli sebelum menggunakan fakta atau jadwal.
- Jangan menghapus atau mengubah isi arsip tanpa kebutuhan dan pencatatan yang jelas.
